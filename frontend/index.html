SupplyTrace

Supplier XML invoice validation · demo
Source on GitHub Built by Vishnu Jayanth

Check a supplier XML invoice in one click. SupplyTrace flattens the nested XML, finds the transaction ID and amount wherever they sit, and applies deterministic rules that label the file VALID, INVALID or REQUIRES_REVIEW. A small Random Forest adds an experimental risk score, and every analysis is written to a JSON Lines audit log.

Synthetic data The dashboard starts from a batch of generated invoices, and the risk model is trained on them. Nothing here is real supplier data, so please don't upload real invoices.
